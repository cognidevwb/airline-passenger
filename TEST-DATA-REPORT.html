  • CSV writes SQL NULL as an empty unquoted field and the empty string as "". That is the only distinction CSV can carry.
  • A BIT column takes one spelling per format, and only one: 1 / 0 in SQL and CSV, which is what a bit column loads from; JSON's own true / false. Whatever a value class or a declared DEFAULT was written as, the output is uniform.

  • A length boundary binds EXACTLY the declared width, and is shaped to the column's own kind at that width: an address for an email column, whole name parts for a person, whole words for free text, a value from the declared vocabulary where one is that long.
