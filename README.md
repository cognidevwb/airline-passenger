# airline-passenger

Passengers with passport number, name, age and passenger type. Completes a registration when the identity service reports a new user, and answers the booking service over gRPC.

Part of the **airline-estate** estate: [meysamhadeli/booking-microservices](https://github.com/meysamhadeli/booking-microservices) `1182f4d`, split into 7 repositories. Clone them all into one folder; project references point at sibling folders.

## Depends on

- airline-platform
- airline-identity (UserCreated event)
